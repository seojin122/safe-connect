# 🛡️ Safe Connect — 가정폭력 예방·지원 통합 플랫폼

데이터 기반 분석과 교육·상담 기능을 결합한 **가정폭력 예방 및 피해자 지원 플랫폼**입니다.  
신고 건수 예측, 시설 격차 시각화, 자가진단, AI 상담, 인식 개선 퀴즈·교육 콘텐츠를 통해 **예방 → 발견 → 지원 → 법률 연결**의 전 과정을 아우릅니다.

---

## 🎯 기획 의도 & 목표

- **사회 문제 배경**
  - 가정폭력 신고 건수는 증가세, 그러나 지역별 피해자 지원시설 격차 존재
  - 피해자 및 시민은 위험 인지·상담·법률 지원 경로에 대한 접근성이 낮음
  - 사회 전반의 인식 부족으로 은폐된 피해 다수

- **목표**
  - 데이터 기반: 지역별 신고 예측 및 격차 분석 → 정책 의사결정 지원
  - 사용자 지원: 자가진단·AI 분석 → 피해자가 즉시 도움을 인식·연결
  - 시민 교육: 퀴즈·콘텐츠 → 인식 개선 및 예방 효과
  - 종합 플랫폼: 예방–발견–지원–법률 연결을 원스톱으로 제공

---

## ⚙️ 구현 기능

### 🏠 Main
- 직관적 메인 페이지 UI (탭: 데이터 보기 / 자가진단 / AI 상담 / 교육·법률 지원)

### 📊 데이터 제공
1. **지역별 가정폭력 신고 예측 및 시설 수 산출**
   - 연도별 신고 추세 예측 (예: 2026 기준)
   - 필요한 시설 수 계산 및 지도/차트 시각화
2. **지역별 격차 지수 및 현황**
   - 상담소·보호소 현황 + 신고율 비교
   - 격차 지수(심각·부족·주의·적정) 등급 시각화

### 🧑‍⚕️ 피해자 지원
1. **자가진단 체크리스트**
   - 간단 문항으로 위험 수준 도출 (심각/위험/주의/안전)
   - 결과에 따라 지역 상담소·보호소 연락처 제공
   - “흔히 간과되지만 폭력일 수 있는 상황” 안내 메시지 포함
2. **AI 상담 챗봇**
   - GPT 기반 상황 분석 → “전문 상담 권장” 응답
   - 직접적 진단이 아닌 **조언·연결 가이드** 강조

### 🎓 교육·인식 개선
- 카드뉴스 + O/X 퀴즈 + 랭킹 시스템 (게임처럼 참여 유도)
- “가정폭력에 대한 오해와 진실” 콘텐츠
- 청소년·일반 시민 대상 예방 교육 모듈
- NGO 캠페인/법률 지원 정보 안내

---

## 🛠️ 기술 스택

- **Frontend**: React, React Router, Chart.js / Recharts, Leaflet.js (지도 시각화)
- **Backend**: Node.js (Express)
- **Database**: MySQL (예상)
- **AI/분석**: GPT 기반 프롬프트 엔진, Python (예측 모델)
- **데이터 소스**:
  - 여성가족부 피해자 지원시설 운영 보고서
  - 경찰청 가정폭력 신고 통계
  - 통계청 지역별 인구 수
  - 오픈데이터 포털 API

## 🚀 시작하기
먼저 아래 명령어로 개발 서버를 실행합니다:
```bash
npm run dev
# or
yarn dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 열어 실행 결과를 확인하세요.

## 📁 폴더 구조

```
public/              # 정적 파일 (폰트, favicon 등)
src/
├── assets/          # 이미지, 아이콘 등
├── styles/          # 공통 색상 파일
├── components/      # 컴포넌트 관리
├── hooks/           # 커스텀훅 관리
├── pages/           # 각 페이지 파일
├── util/            # 공통 로직 함수
```

## ✨ 컨벤션
- pages, components 폴더의 파일 이름은 대문자로 시작해 주세요 (예: `Header.tsx`)
- 브랜치는 `feat_OOO` 형식으로 만들어주세요. `feat` 이후에 오는 첫 알파벳은 대문자로 해주세요 (예: `feat_Home`)
- 이미지 파일 이름은 소문자로 관리해주세요.
- 각 폴더에 맞게 분리해주세요.
- `App.tsx` 파일이 화면 구성 파일입니다.
- `src/components/`에 각각 페이지 별로 파일을 만들어, 각 파일에 맞는 컴포넌트를 개발해 주시기 바랍니다.
- `src/pages/`에 각각 페이지 별로 폴더를 만들어, 각 폴더 내부에서 맞는 페이지를 개발해 주시기 바랍니다. (컴포넌트 합치는 용)
- `src/styles/variables.css` 폴더에 공통 컬러를 정의해 두었습니다. css 적용 시 참고 바랍니다. 색 추가 가능합니다.
